# 🖥️ Desktop App Tester Skill

A comprehensive AI skill that transforms any AI agent (Gemini, Claude, GPT) into a **professional desktop application QA tester and security auditor**.

## 🎯 What This Skill Does

When loaded by an AI agent, it forces the agent to perform a **13-phase exhaustive analysis** of any desktop application codebase, covering:

| Phase | Focus |
|-------|-------|
| 1 | Architecture Review |
| 2 | UI/UX Testing (windows, DPI, keyboard, accessibility) |
| 3 | Logic & Functional Testing |
| 4 | **Security Audit** (DLL injection, IPC, privilege escalation + mandatory web search) |
| 5 | Performance Analysis |
| 6 | Platform Compatibility (Windows/macOS/Linux) |
| 7 | API & Network Resilience |
| 8 | State & Data Management |
| 9 | Error & Crash Prevention |
| 10 | Final Delivery + **Fresh-Eyes Re-Analysis** |
| 11 | Structured Remediation (with Hacker Mindset R6 verification) |
| 12 | Distribution & Commercial Readiness |
| 13 | **Pre-Delivery Sentry Validation** |

## 🛡️ Anti-Laziness Features

- **91 minimum code citations** required across all phases
- **Mandatory web search** for current-year vulnerabilities (no stale training data)
- **Fresh-Eyes re-analysis** — forces a second independent pass to catch missed issues
- **4-layer reminder system** — impossible for the AI to forget critical steps
- **Hacker Mindset R6** — post-fix security verification from attacker's perspective
- **Cross-Reference Matrix** — proves every file was actually examined

## 🔧 Supported Frameworks

Electron, WPF, WinForms, .NET MAUI, Qt (C++/Python), JavaFX, GTK, Tauri, Flutter Desktop, SwiftUI (macOS), Avalonia, PyQt/PySide

## 📦 How to Use

1. Load this skill folder into your AI agent's skill/plugin system
2. Tell the agent: "Run the desktop app tester skill on my project at [path]"
3. The agent will execute all 13 phases automatically with stop points
